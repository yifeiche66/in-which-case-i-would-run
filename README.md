# in which case i would run

An animated poem. Words rise one by one inside a glass circle and dissolve where they touch its wall. Tapping the page stirs them upward.

- `index.html`: the piece. Open it in a browser.
- `media/in-which-case-i-would-run.mp4`: a recording of one full run, tapped as each "tap" appears.

Press space to pause.
